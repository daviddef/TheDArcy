# Requests

Two kinds of file live in this archive, and they are not the same thing.

**`requests/`** — jobs **David has to run himself**, because they need a login, a card payment, an
identity check, or a bot check that I will not attempt to defeat. Each file says what the source is,
why it matters, the exact searches to run, and what to send back.

**`notes/letters/`** — **drafted letters** to institutions, ready to send. They are drafts only;
nothing here has been sent, and nothing will be sent without David deciding to.

## A note on negative results

Several of these may come back empty. That is a result, and it gets recorded on
`/open-questions` under *what has been read and found empty* — so that the next person does not
repeat the search. An archive that only records its successes is telling you half the truth.
